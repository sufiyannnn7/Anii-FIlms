Build a world-class premium personal portfolio website for a creative professional specializing in Marketing Strategy, Branding, Creative Direction, and Filmmaking.

IMPORTANT:
This is ONLY the frontend.
Do NOT build authentication, backend, APIs, or a database.

However, architect the frontend so it can later connect seamlessly to Supabase or Firebase. Every piece of content (projects, categories, gallery, text, videos) must be loaded from reusable mock JSON/TypeScript data instead of being hardcoded.

The final website must feel like an award-winning Awwwards-level creative portfolio with cinematic interactions, premium typography, smooth motion, and exceptional UX.

IMPORTANT

The frontend must be designed so that after connecting a backend, the client can log into an admin dashboard and:

• Add projects
• Edit projects
• Delete projects
• Upload posters
• Upload gallery images
• Upload thumbnails
• Add YouTube/Vimeo links
• Select section (Filmmaking or Marketing)
• Select category (Short Film, Marketing Strategy, etc.)
• Publish instantly

When a project is published, it should automatically appear in the correct section and category without requiring any frontend changes.

Do NOT build these backend features yet—only prepare the frontend architecture for them.
